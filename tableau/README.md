# Tableau Public

**Live viz:** [Sellthrough – Buyer Fee Pilot](https://public.tableau.com/app/profile/amit.bhattarai7047/viz/Sellthrough-BuyerFeePilot/Sheet1)

`weekly_checkout_conversion.csv` and `fee_pilot_before_after.csv` are pre-aggregated with the
same logic as the queries in [`../bigquery/`](../bigquery), so the workbook plots rates directly.

The published chart shows weekly checkout-to-order conversion for pilot and control markets:
both run near 44% until late July, then the pilot line drops to about 40% after the fee rose on
Aug 1 while control holds steady.
